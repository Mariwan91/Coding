# HumanRead

موقع يأخذ **نصًا عربيًا** ويحوّله إلى **اللهجة العراقية** ثم **يقرؤه بصوت مسموع** (مع تظليل الكلمة أثناء القراءة).
نسخة خاصة للتجربة على سيرفرنا — لا نشرها للعامة حاليًا.

## التشغيل المحلي
```bash
cd humanread
npm start            # http://localhost:3000
npm test             # الاختبارات
```
لا حاجة لتثبيت أي حزمة (Node.js 18+ فقط).

## الرفع على السيرفر الخاص (نسخة تجريبية غير عامة)
1. انسخ المجلد إلى السيرفر وثبّت Node.js 18+.
2. شغّله مع **كلمة سر** حتى لا يدخله إلا من تعطيه إياها:
   ```bash
   ACCESS_PASSWORD='كلمة-سر-قوية' PORT=3000 npm start
   ```
   سيطلب المتصفح كلمة السر عند فتح الموقع (اسم المستخدم أي شيء).
3. للتشغيل الدائم استخدم `pm2 start server.js --name humanread` أو خدمة `systemd`.
4. يُفضَّل وضع HTTPS أمامه (مثل Caddy أو Nginx)، لأن كلمة السر تُرسل مع كل طلب.
5. اقتراحات التصحيح تُحفظ في `data/suggestions.jsonl` على السيرفر.

## وضع الذكاء الاصطناعي (موصى به للدقة)
القاموس لا يغطي كل النصوص (نصوص الأعمال والعلوم وغيرها مفتوحة المفردات). لذلك أضفنا وضعًا اختياريًا يستخدم Claude لتحويل أي نص إلى العراقية وإنتاج نص **مشكَّل** للقراءة الصوتية:
```bash
ANTHROPIC_API_KEY='sk-ant-...' ACCESS_PASSWORD='كلمة-سر' npm start
```
- يُفعَّل تلقائيًا عند وجود المفتاح؛ وبدونه يبقى القاموس. خيار «استخدم القاموس فقط» في الصفحة.
- إن فشلت الخدمة يرجع الموقع للقاموس تلقائيًا مع تنبيه.
- النموذج الافتراضي `claude-sonnet-5-5` ويمكن تغييره بـ `ANTHROPIC_MODEL`. كل تحويل يُحسب على مفتاحكم.
- النص يُرسل إلى خدمة Anthropic للتحويل، فلا تدخل نصوصًا سرّية إن لم يناسبكم ذلك.

## كيف يعمل
- `src/engine.js` — محرك التحويل: عبارات، سوابق (و، ف، ب، ل، ال)، نفي (لا/لم/لن)، مستقبل (سأذهب ← راح أروح)، حذف «هل» و«أن»، الحروف العراقية (گ، چ).
- `src/dialects/iraqi.js` — قاموس العراقية وجداول تصريف الأفعال. **هنا يُحسَّن مستوى الدقة.**
- `public/` — الواجهة. القراءة تستخدم أصوات المتصفح (Web Speech)؛ **Microsoft Edge** يوفّر صوتًا عراقيًا حقيقيًا (`ar-IQ`).
- الضغط على أي كلمة متغيّرة: يعرض الأصل والبدائل ويتيح اقتراح تصحيح.

## API
- `POST /api/convert` `{ "text": "...", "dialect": "iraqi" }`
- `POST /api/suggest` `{ dialect, source, current, suggestion }`
- `GET /api/dialects`, `GET /api/health`
