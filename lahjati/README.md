# لهجتي — قارئ اللهجات العربية

منصة ويب (Full-Stack) تحوّل النص العربي الفصيح إلى لهجات الدول العربية (والعكس) وتقرؤه بصوت مسموع مع تظليل الكلمة أثناء القراءة. تبدأ باللهجة **العراقية**، والمصرية بنسخة تجريبية، وبقية اللهجات مخطَّط لها.

## التشغيل

```bash
cd lahjati
npm start          # ثم افتح http://localhost:3000
npm test           # الاختبارات
```
لا حاجة لتثبيت أي حزمة (Node.js 18+ فقط). المنفذ يتغير بـ `PORT=8080 npm start`.

## المزايا
- تحويل **فصحى ← لهجة** و**لهجة ← فصحى**.
- قاموس وقواعد: تصريف الأفعال، النفي (لا/لم/لن)، المستقبل (سأذهب ← راح أروح)، السوابق (و، ف، ب، ل، ال)، حذف «هل» و«أن»، الحروف العراقية (گ، چ).
- الضغط على أي كلمة متغيّرة: يعرض الأصل والبدائل، ويتيح **اقتراح تصحيح** يُحفظ في `data/suggestions.jsonl`.
- القراءة الصوتية عبر أصوات المتصفح (Web Speech): اختيار الصوت والسرعة، إيقاف مؤقت، تظليل الكلمة. أفضل نتيجة للعراقية في **Microsoft Edge** (صوت `ar-IQ`).
- سجل آخر التحويلات، وضع داكن تلقائي، متجاوب مع الجوال.

## البنية
```
server.js                خادم HTTP + API
src/engine.js            محرك التحويل (تقطيع، عبارات، سوابق، قواعد سياقية)
src/dialects/iraqi.js    قاموس العراقية (نموذج لبقية اللهجات)
src/dialects/helpers.js  مساعد تصريف الأفعال
public/                  الواجهة (HTML/CSS/JS)
test/                    اختبارات
```

## إضافة لهجة جديدة
1. انسخ `src/dialects/egyptian.js` إلى ملف جديد وعدّل `entries` و`verbs` و`speech` و`future`.
2. أضفه في `implemented` داخل `src/dialects/index.js` وأزله من `planned`.
3. شغّل `npm test` — اختبار «سلامة القواميس» يفحص بنية القاموس تلقائيًا.

## API
- `GET /api/dialects`
- `POST /api/convert` `{ "text": "...", "dialect": "iraqi", "direction": "toDialect" | "toMsa" }`
- `POST /api/suggest` `{ dialect, direction, source, current, suggestion }`

## خارطة الطريق
الشامية والخليجية والمغاربية · قاموس أوسع من اقتراحات المستخدمين · صوت عصبي من الخادم (مثل Azure `ar-IQ`) لقراءة موحّدة على كل الأجهزة · قاعدة بيانات للاقتراحات ولوحة مراجعة.
